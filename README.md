# 声签

声签是一款按内容需求工作的播客搜索工具。用户输入一个问题，产品从不同播客中匹配相关时间片段，并将它们整理成一份连贯的声音拼盘。

## 当前 MVP

- 直接接受自然语言问题，不做多轮对话识别；
- 模拟检索与拼盘生成状态；
- 五段式职业选择主题内容拼盘；
- 片段级播放、进度与固定播放器；
- 展示节目、单集、嘉宾、原始时间点和选择理由；
- 提供 Supabase PostgreSQL + pgvector 数据结构。

当前样本数据位于 `app/mock-data.ts`，仅用于产品体验演示。播放器使用浏览器语音合成朗读样本文字，不包含或重新分发真实播客音频。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可。

## 关键文件

- `app/page.tsx`：完整产品体验与播放器交互；
- `app/mock-data.ts`：结构化模拟检索结果；
- `docs/product-architecture.md`：产品架构、用户流程和后续范围；
- `supabase/schema.sql`：Supabase 数据表、索引和向量检索函数；
- `.env.example`：第二阶段服务端接入所需变量。

## 数据接入原则

真实版本建议通过 RSS 获取公开元数据，只转录自有、授权或开放许可音频。完整单集应优先跳转到内容方允许的原始地址。
